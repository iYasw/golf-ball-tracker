# Golf Ball Tracker

iPhone（iPhone 15 Pro を想定）で撮影したゴルフ動画から、白いボールの**画面上の軌跡**を追跡する Web アプリです。
動画は端末内（ブラウザ内）だけで処理し、サーバーへは送信しません。

## 試験版の画面と保存
- 上部の「カメラ」（初期表示）／「動画」を切り替えます。100dvhとセーフエリアに対応し、iPhoneの393×852・430×932 CSS pxでスクロールせず使う設計です。
- 映像は残りの高さに収め、ガイド・軌跡も同じ余白で重ねます。結果は映像上のコンパクトなパネルに表示します。
- カメラ取得後、ブラウザが公開する最大fpsを要求します。1280×720程度を優先し、制約が通らなければ解像度制約を外す／fpsを下げて再試行します。実際の設定fpsを「撮影 … fps」に表示します。
- ブラウザからはカメラアプリの240 fpsスローモーションを自由に利用できません。端末・ブラウザが提供する撮影fpsが上限です。ライブの速度はカメラの時刻に基づくpx/秒です。
- 「準備OK」で録画を開始し、結果表示の1.5秒後に停止します。対応時はMP4、それ以外はWebMです。MediaRecorder非対応のブラウザでは動画保存は使えません。
- 「画像を保存」で打ち出し時の画像・太い軌跡・開始円・観測値・日時・fpsを合成したPNGを保存します。「動画を保存」は録画完了後に使えます。ファイル共有対応時は共有画面、それ以外は `golf-shot-YYYYMMDD-HHMMSS.png`（動画はmp4/webm）をダウンロードします。「次のショット」で再準備できます。
- 試験版です。撮影fpsと解析fpsは異なり、実機Safariでの動作・共有先への保存は端末による確認が必要です。データは端末内で処理します。

## できること
- 端末の動画を選ぶ／サンプル動画で試す
- 再生・一時停止、スライダーと 1 フレーム送り・戻しによる位置調整
- 動画上のボールをタップして開始位置を指定 → 白いボールを自動追跡
- 軌跡（黄色の線）と開始位置（緑の円）を動画に重ねて表示
- 画面上の観測値：打ち出し直後の画面速度（px/再生秒）、画面上の打ち出し角度（右／左方向）、画面上の移動距離、打ち出し後の追跡時間

## 観測値と推定値の区別
表示値はすべて**映像上の観測値**です（px＝動画の画素、秒＝動画の再生時間）。
実空間の初速・打ち出し角度・キャリーは未実装です。将来追加する場合は、カメラ位置・距離・既知の長さなどによる**校正に基づく推定値**として、観測値と区別して表示します。

## 使い方
1. 「動画を選択」で撮影した動画を選ぶ（または「サンプル動画で試す」）
2. フレームレートを動画に合わせる（スロー撮影の元データは 240 fps など）
3. アドレス時や打たれる直前のフレームに合わせ、ボールをタップすると自動で追跡を開始
4. 軌跡と結果を確認。再実行するときは「もう一度追跡」

## 追跡の仕組み
- 打つ前：タップした位置の白いボールを明るさで見つけ、位置・大きさ・明るさを記憶する。ボールが見えている間はクラブなどの動きを無視して待つ（最大 600 フレーム）
- ティー上のボールが異なる画像で 2 回続けて見えなくなり、ボール大のかたまりが離れていくと打ち出しを確認。一時的にクラブに隠れただけなら、ボールが戻った時点で仮の軌跡を取り消す
- 打った後：前のフレームから**動いた**色の薄いかたまりをボール候補にする（芝の上の灰色にぶれたボールにも対応。動かない白い点や置いてあるボールは無視）
- 移動の速さに合わせて探す範囲を広げ、進行方向がそろっていること・ボールの大きさ・丸さ・明るさで候補を選ぶ（後ろから来るクラブヘッドを区別）
- 同じ画像が続くフレーム（iMovie などのスロー加工）は飛ばす
- 打った後に 6 フレーム続けて見つからなければ終了
- 各フレームの中央の時刻へ移動して解析（端数の誤差で前のフレームを読まないため）
- 大きな動画は解析用に幅 1280 px まで縮小（座標は元の画素に戻して表示）

## リアルタイム・試験版カメラ解析
初期表示の「カメラ」タブでは自動でカメラを起動します。カメラの使用を許可してください。自動起動がブラウザに拒否された場合は、映像内の「カメラを起動」を押してください。HTTPS（開発時は localhost）が必要です。音声は取得しません。

ゴルファーの後方から、ボールを画面左下の円、体を右側の輪郭に合わせます。「左打ち」に切り替えると左右が反転します。ガイドは縦横どちらの映像でも同じ比率で表示されます。枠内の白いボールが0.5秒静止すると「準備OK：打ってください」になります。クラブが近くで動いても、静止球が残っている間は打ち出しと判定しません。

打ち出し後は自動追跡し、見失った時点、または打ち出し確認から3秒で結果を表示します。打ち出し時の画像に、暗い縁取り付きの太い黄色の軌跡を重ねます。表示は画面上の観測値（px/秒、角度、移動距離、追跡時間）で、実際の飛距離や初速ではありません。解析速度は「コマ/秒」で表示します。解析幅は最大960 pxです。

結果を2秒以上表示した後、枠内に静止球を置くと次のショットを自動準備します。「次のショット」でもリセットできます。打たずにボールを取り除くと位置合わせに戻ります。ページを隠す・離れるとカメラを停止します。再開時はもう一度「カメラを起動」を押してください。

## 録画した動画の解析
上部の「動画」タブから従来の動画選択・フレーム送り・タップ開始が使えます。現在のフレームでガイドの円内に白いボールが見つかる場合は「枠内のボールで追跡」でも開始できます。
